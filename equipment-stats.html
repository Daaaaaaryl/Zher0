Rounding / Decimal Audit
Ideal decimal allocation is shown before whole-number rounding. Largest remainder is used so the required pool is preserved exactly.

    

  


  

    Prototype rule currently being tested:

    1. Priority is a strength/use level, not a ranking order.

    2. Priority 10 is a stronger allocation weight than Priority 8, which is stronger than Priority 4, etc.

    3. Blank/0 means no allocation.

    4. Whole-number rounding uses largest remainder so the required positive pool is not lost.

    5. Negative values are returned to the positive allocation pool, then applied as deductions; this keeps the final total equal to the original Total Basis.

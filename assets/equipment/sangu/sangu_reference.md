# Sangu art reference

- Equipment: Sangu
- Slot: Off Hand
- Status: Approved source assets
- Finalized Equipment artwork: `sangu_master.png`
- Final Balancing artwork: `sangu_tuner.png`
- Icon: pending

## Set definition

Sangu is one equipment item composed of a matched protection set:

- Kote — arm protection
- Haidate — thigh/waist protection
- Suneate — shin protection

These components must not be split into separate equipment registry entries.

## Asset handling

`sangu_master.png` is the canonical approved complete-set artwork for the Finalized Equipment presentation. `sangu_tuner.png` is the canonical approved vertical artwork for the UI called Final Balancing; its filename retains the established Tuner asset convention.

Both PNG files are approved source-of-truth assets representing the same Sangu equipment set. Do not regenerate, redraw, crop, rotate, recolor, resize, enhance, compress, optimize, or otherwise transform either file. The UI must not automatically transform one artwork to fabricate the other. The icon remains pending and must not be generated from description alone.
